🎯 CONCEPT
─────────────────────────────────────────────────────────────────────────
Application d'entraînement interactif à la concentration et aux réflexes.
Le joueur doit cliquer sur des cibles apparaissant aléatoirement avant leur
disparition. Mesure: vitesse de réaction, précision, score, combo, progression.

🏗️ ARCHITECTURE
─────────────────────────────────────────────────────────────────────────
Framework: React 18.3.1 + Vite 5.1.3
Routing: React Router v6
State: Context API
Storage: LocalStorage
Styling: CSS pur (pas de dépendances externes)
